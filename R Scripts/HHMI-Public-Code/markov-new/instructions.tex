The markov-new folder contains two R scripts for producing Markov
models of one class (markov-one-class) or two classes
(markov-two-class). These scripts require two to three data files
(examples in the input-dataset folder). Both files have rows
representing students (in the same order) and columns representing
semesters).

Enrollment data file: Enrollment data for students by semester
classified as: 1 - Enrolled as target major (EM), 2 - Enrolled as
some other major (ENM), 3 - Not enrolled as university and not
graduated (NE), 4 - Graduated with target major (GDM), and 5 -
Graduated with other than target major (GDNM). All but EM should
be absorbing states; once a student enters, they never leave.

Class data file (one per class of interest): This file contains
the student's grade by semester coded as 4=A, 3=B, 2=C, 1=D, and
0-F or Withdraw. If the student did not take the class during the
semester, -1 is entered.

The code should run with the sample data once the packages are
installed. The figures are saved to output-plots
