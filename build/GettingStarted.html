Getting Started

Ready to start using the Student Success tools generated for LCC5 Project B? To use these tools, you will need to install Python on your computer and install a series of python modules.

Installing Python

For Windows

  1. Download and install Python:

    • Navigate to the official Python website.

    • Download the latest version of Python for Windows.

    • Run the installation file and follow the prompts. The default settings are generally acceptable, but make sure you check the box that says “Add Python to PATH” before proceeding.

  1. Verify Installation:

    • Open a command prompt by pressing Win + R, typing cmd, and pressing Enter.

    • Type python --version and press Enter. You should see the installed version of Python displayed.

For Mac

  1. Install Homebrew (if not already installed):

    • Open Terminal, which you can find in /Applications/Utilities/ or by searching for it in Spotlight.

    • Paste the following command and press Enter:

      /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

  2. Install Python using Homebrew:

    • In Terminal, type the following command and press Enter:

      brew install python

  3. Verify Python Installation:

    • Open Terminal (or Command Prompt on Windows).

    • Type the following command and press Enter:

      python --version

    • You should see the installed version of Python displayed in the terminal output.

Installing Python Modules and Setting up Environment Variables

  1. Open a python console

  2. Run the following command:

    pip install pandas numpy matplotlib tabulate statsmodels pydot pygraphviz
  3. Test import of your modules

    • In the python console, run the following:

    import institutionaldata.successmetrics
import institutionaldata.utilityfunctions

    • If you have no errors, congratulations! You are ready to import some data and run the functions.

  4. Add ‘STUDENT_SUCCESS_CIPHER’ environment variable. This environment variable is used to de-identify student ID numbers.
    • For Windows

      1. Open the Control Panel.

      2. Navigate to System and Security.

      3. Click on System.

      4. Choose Advanced system settings from the left sidebar.

      5. In the System Properties window, click on the Environment Variables button.

      6. Under System Variables, click on New.

      7. Enter ‘STUDENT_SUCCESS_CIPHER’ in the Variable name field.

      8. Enter the desired value for ‘STUDENT_SUCCESS_CIPHER’ in the Variable value field. This should be an alphanumeric code known only to you. It should be the same length of the number of digits used by your institution for student ID’s.

      9. Click OK to save the variable.

    • For MacOS

      1. Open Terminal.

      2. Type nano ~/.bash_profile and press Enter.

      3. Add the following line at the end of the file. Replace your_value_here with the desired value for ‘STUDENT_SUCCESS_CIPHER’. This should be an alphanumeric code known only to you. It should be the same length of the number of digits used by your institution for student ID’s.

        export STUDENT_SUCCESS_CIPHER="your_value_here"

      4. Press Ctrl + X to exit nano.

      5. Press Y to confirm changes, then press Enter to save the file.

      6. After saving the file, type source ~/.bash_profile and press Enter to apply the changes to the current Terminal session.

Importing your Data

  • Load your data into Python
    1. Open columnmapping.tsv file (in institutional data folder) and update the names of the fields in the ‘variable_name_institution’ column with the column names used in your dataset
      # This file is used by utilityfunctions.rename_columns_in_bulk() in order to rename columns to a standardized format
# for multi-institutional usage. variable_name_project is a column comprised in which standard field names are placed,
# and variable_name_institution holds comma-separated variants that refer to this variable at any institution. Do not
# include any white spaces after the comma in the list.
# The description column is provided so we can write out common definitions
variable_name_project   variable_name_institution   description
major_matriculation     MAJOR_MATRICULATION,MAJOR_Matriculation
major_term              major,SDSTUMAIN_MAJOR,StuMajr_Code1
major_graduation
term_matriculation      MATRIC_TERM,SDSTUMAIN_MATRIC_TERM
student_ID              WHKEY,ID,PantherID,SDSTUMAIN_WHKEY,Student_ID,Pidm
flag_first_generation   FIRST_GENERATION_IND
    2. Run the following from the python console
      import os
from dotenv import load_dotenv
import pandas as pd
import numpy as np
import sys
sys.path.append('../../')
import institutionaldata.successmetrics
import institutionaldata.utilityfunctions
import statsmodels.api as sm
load_dotenv()
column_mapping_file_path = r'.\institutionaldata\column_mapping.tsv'

data_filepath = "copy_the_full_file_path_for_your_CSV_formatted_file_here"
dataset_df = pd.read_csv(data_filepath)
dataset_df = institutionaldata.utilityfunctions.rename_columns_in_bulk(dataset_df, column_mapping_filepath = column_mapping_file_path)
dataset_df = institutionaldata.utilityfunctions.scramble_ID(dataset_df, cipher=os.environ['STUDENT_SUCCESS_CIPHER'])
    3. Verify that that the column names were changed.
      print(list(dataset_df))

    4. Congrats! Now you should begin exploring the functions in studentsuccess.py and utilityfunctions.py. As you start, you will encounter challenges and errors. These arse normal and reflect the first step in every data analytics project: data-cleaning. These steps will vary depending on the format your institution provides data to you. While python error messages are informative, they can be overwhelming at first. Users are welcome to reach out to the Project B team for assistance in troubleshooting. Also consider using ChatGPT to help you troubleshoot. If you provide ChatGPT with an error message, you can iteratively determine what part of your code or command is incorrect. Of course, bugs will occur in the code too! Please document problems that arise and post any questions to #project-b on Slack.
